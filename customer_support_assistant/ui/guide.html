Quick start

Run your first workflow

  1. Return to the dashboard and enter a ticket ID, customer tier, subject, and customer message.
  2. Start the five-agent workflow.
  3. Inspect classification, priority, approved guidance citations, and recommended response.
  4. Open the new history row to review the retained input and evidence.

Multi-agent design

What the agent team does

  • Intake validates the ticket and creates workflow context.
  • Classification identifies support category and operational priority.
  • Knowledge retrieval selects approved support guidance.
  • Response composition creates a customer-ready answer.
  • Persistence stores the governed outcome in PostgreSQL.

Dashboard

How to read the charts

  • Activity shows completed workflows over the last 14 days.
  • Priority mix highlights operational urgency in recent cases.
  • Classification mix shows which support topics are driving demand.

Human control

What to verify

  • Review source evidence before acting on the output.
  • Use workflow history and trace links for investigation.
  • Never paste credentials or sensitive customer data into a demonstration.

Recommended client narrative

Seven-minute demo script

  1. Start with the dashboard to explain support volume and demand mix.
  2. Enter a concise account-access ticket and select a premium customer tier.
  3. Point out that premium tiers can raise priority without changing the evidence.
  4. Run the workflow and explain the five specialized responsibilities.
  5. Open the result to show citation-grounded guidance and traceability.
  6. Use search and history to demonstrate operational handoff.
